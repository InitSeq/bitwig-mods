# Coldforge Bitwig Mods

Mods for Bitwig Studio, loaded with [Patchbay](https://github.com/shaboogen-dev/Patchbay). Not affiliated with Bitwig GmbH.

| Mod | Download |
|---|---|
| Piano Roll: Note Generator | `note-generator-0.2.0-dev.1.zip` |

Get the ZIPs from [Releases](../../releases) and add them in Patchbay with **Mods → Add Mod…**, or add this repository as a mod source in Patchbay Launcher.

- [Piano Roll: Note Generator](note-generator/README.md): generates chords or a melody in the project's key, laid out in a form such as A A A B, from a block in the Inspector. Prototype, for Bitwig Studio 6.1.7 on macOS.
